# Lisensi Aset — Baca Ceria

- **Kode & gambar prosedural** (UI "Ceria", latar, maskot Kiko, gambar kata, bintang): karya proyek ini.
- **Font Baloo 2** (700, 800) & Fredoka (600, cadangan): SIL Open Font License 1.1 — © The Baloo Project / Ek Type; © Fredoka project. Boleh dibenamkan di aplikasi komersial.
- **Narasi suara**: disintesis dengan **Piper TTS** (mesin MIT) memakai model suara `id_ID-news_tts-medium` (dataset berita bahasa Indonesia; periksa kartu model untuk penggunaan komersial sebelum distribusi berbayar skala besar; rencana produksi: ganti dengan rekaman suara manusia).
- **SFX** (pop, hore, lembut): disintesis dari kode (numpy) untuk proyek ini.
- Paket Kenney UI Pack (CC0) tersedia di arsip dev dan TIDAK dipakai dalam build ini (UI digambar prosedural agar konsisten).
